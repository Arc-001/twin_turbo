Hybrid Edge / Digital-Twin Prognostics

Turbofan
Prognostics Deck

A tiered RUL estimation system for a fleet of turbofan engines — a cheap model runs every cycle, a higher-fidelity twin is called in only when it disagrees, and a fixed policy turns the result into an action.

01 — Architecture

One policy, two models, different price tags.

The edge model is a compact tree-based regressor, fast enough to run every single cycle on-device. It alone decides nothing critical — it only proposes an estimate. The digital twin is a heavier sequence model that reconstructs a full degradation trajectory and reports its own uncertainty, but it is only worth invoking when the situation actually calls for it. A fixed set of triggers decides when that is.

02 — Results

Four operating conditions, one method.

FD001/FD003 run at a single flight condition; FD002/FD004 run across six, which is why their errors sit higher — more regimes, noisier signal, harder problem. The twin trails the edge model's point accuracy everywhere; its job is the uncertainty band and the escalation trigger, not raw RMSE.

03 — Scenario replay

Four engines, replayed cycle by cycle.

Each scenario streams one held-out test engine through the live pipeline: the edge model runs every step, the twin joins when a trigger fires, and the policy calls a zone from the confidence-adjusted estimate. True RUL is shown for reference only — the system never sees it.
